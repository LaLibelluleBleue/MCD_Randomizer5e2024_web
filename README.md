# MCD_Randomizer5e2024_web 

Random character creator for D&D 5e 2024. 

One player character is randomly created by either rolling physical dice or letting the app roll automatically. Once the basics (race/class/background) are established, a backstory can be automatically generated loosely based on the old "This is your life" annex to Xanathar's Guide. The random backstory can be kept as is, or it can be used as a writing prompt or starting point to write your own. The biography/backstory can be edited directly in the window and saved. All NPCs generated by the automatic backstory are listed, and if any adventurer NPC exist, they can also be further developed to get their own random backstory. All adventurers created and their relationship with each other are mapped to visualize the PC's entourage. 

# For users

The software can be run from either the github address page, or locally if the index.html file is downloaded.
It is recommended to save a copy of any character log file so that it can be reloaded/modified at a later date if required.

# Developer Workflow : notes on how to change CSV input files and update the index.html

As of V1.1, all character option data is stored in CSV files that can be updated.
Versions 1.2 are iterations on the creation and mapping of the character's entourage.
Version 1.3 will include character options from EFotA, AU and RtHW expansion books.

Edit the CSVs in the data folder, then run python build.py. It rebuilds index.html, and template.html holds the app code.
Weights/probabilities of each character options are relative, so you can add rows without rebalancing to 100. You can also add extra columns.
Save CSVs as “CSV UTF-8” so the accents survive.
For GitHub, upload index.html for the live app, and also template.html, build.py and the data folder so everything is versioned together.
